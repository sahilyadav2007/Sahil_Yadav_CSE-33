# FSD Practical Codes

Complete Node.js lab practical programs arranged by experiment.

## Folder Structure

```
C:\fsd practicle\
├── exp1\
│   ├── partA.js    # Part A – Custom EventEmitter for Greet and Exit Events
│   ├── partB.js    # Part B – Simulate DOM-Like Event Handling in Node.js
│   └── partC.js    # Part C – Visualize the Event Loop Using Node.js
├── exp2\
│   └── exp2.js     # Experiment 2 – CRUD Operations on Files using fs module
├── exp3\
│   └── exp3.js     # Experiment 3 – Basic HTTP Server on Port 3007
└── package.json
```

---

## How to Run in VS Code Terminal

Open terminal (`Ctrl + \``) in VS Code inside `C:\fsd practicle`:

### Experiment 1 (All parts in `exp1` subfolder)
- **Part A:**
  ```bash
  node exp1/partA.js
  ```
- **Part B:**
  ```bash
  node exp1/partB.js
  ```
- **Part C:**
  ```bash
  node exp1/partC.js
  ```

### Experiment 2
- **File CRUD Operations:**
  ```bash
  node exp2/exp2.js
  ```

### Experiment 3
- **HTTP Server:**
  ```bash
  node exp3/exp3.js
  ```
  Visit: [http://localhost:3007](http://localhost:3007)
